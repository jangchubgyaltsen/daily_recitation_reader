# 数据格式（第一步）

## 原则
- 每部仪轨一个**纯文本源文件**（`rituals/*.txt`），用任何编辑器都能打开校对。JSON 是程序自动生成的，不用手改。
- 键可以随时新增（比如加 `fr:` 法文、`audio.bo:` 录音），程序不用改。
- 译文、音译只用法本原文，不自行生成。唯一由 Claude 起草的是逐词对应（`gloss`），标记为待校对。
- 每部仪轨都有 `@restriction`：`public` 或 `empowerment_required`（后者默认不公开）。

## 文件
- `rituals/eight-auspicious.txt`：圣八吉祥颂，40 句，分 6 段
- `rituals/multiplying-mantra.txt`：加倍咒，单独模块，默认三遍
- `tools/check.py`：校对检查，改完运行一下，它会指出音节对不上或逐词对应不完整的地方，并生成 JSON

## 来源
- 藏文、汉文、汉文音译：喇荣课诵 2024-05-02 版
- 英文、英文音译：Larung Daily Chant Book 2021（Rigpa Translations）
- 英文译文是整段意译，句序和藏文不一一对应，所以挂在段落上，不挂在每一句上。
- 一律以中文版为准。两版藏文不一致的地方记在 `variant:` 里，仅供参考。
- 目前重点是藏汉。英文和英文音译已存在文件里，第一版界面先不显示，以后打开即可，数据结构不用改。

## 对齐方式
- 汉文音译按字对应藏文音节；`{额巴}` 这样括起来的算一个音节。
- 英文音译按词对应（如 nangsi 对 སྣང་སྲིད），高亮时整个词一起亮。

## 音频（第三步）
- 三种音轨：`bo` 藏文念诵、`zh` 中文念诵、`tune` 只有调子。
- 仪轨信息里写录音文件：`@audio.bo: audio/eight-auspicious.bo.mp3`
- 每句写节拍开始的时间（秒）：`t.bo: 12.3 13.1 13.85 14.6`，按律每节一个数；中文念诵每句只记开头一个数。句子结束 = 下一句开始。
- 时间点用阅读器里的“跟着录音标注节拍”工具来点，点完“复制时间点”就能得到上面格式的文字。
- 逐字高亮：在一节的时间里，按音节数平均分配。

## 藏文发音词库（2026-10-25）

- 点词播放的是「纯发音」，来自共用词库 `lexicon/bo/`，不是念诵录音，也不在网页里直接跑模型。
- 一个词只存一次：`index.tsv` 记录 词 → 文件（文件名由词算出），不同仪轨里的同一个词共用。
- 加新仪轨后：`python3 tools/lexicon.py missing` 列出词库缺的词 → 在 w 电脑上用 `tools/mms_tts.py`（安多模型 facebook/mms-tts-adx，每个词合成时末尾都补 ་（w 定的规则，以后新词也一样，否则模型会吞掉最后的音），语速 0.8，前留 0.08 秒、后留 0.35 秒空白，ཾ 按 མ 念）生成，附 manifest.tsv（id file duration_seconds text）→ `python3 tools/lexicon.py import <目录>`。已有的词不覆盖。
- `build_app.py` 只把用到的词嵌进阅读器，并写出 `app/lexicon-files.txt`，发布时要带上这些文件。
- 已知问题写在 index.tsv 的 note 栏：ཨོཾ、པི་ཝཾ 缺尾音 m（模型不认识 ཾ）。
- 点一句的空白处播放这一句的念诵录音。「只有调子」= 静音的念诵 + 按节拍敲木鱼。

### 挑发音与连读版（2026-10-25）
- 挑选页 tools/build_picker.py + picker_template.html，选择存在页面数据库 picks/<词id>（v = a..f 或 none）。页面显示书里的音译（音节 zh_ph 拼词、en_ph、意思）。
- 候选：a=原版 seed0；b/c=seed1/2；d/e=低噪声；f=「连读」：整句合成（词之间用 ་ 连接，末尾补 ་），用 duration_predictor 的时长对齐（每帧 256 采样，add_blank 下第 i 个字符=第 2i+1 个 token），开头切在本词第一个字母处（附近最安静的点，无余量，10ms 淡入），结尾在 ་ 中点加 30ms（下一个词已经起音时收到最安静点），15ms 淡出；第一版切法在 f_v1/。只给每个词第一次出现的句子做。
- w 提出：藏文会连读变音，所以单独念一个词可能不准。
- 候选文件在 lexicon/candidates/bagui-tts-cand/，句子列表在 lexicon/candidates/lines_ctx.tsv。
- g=「前连」：只合成「前一个词་本词་」，开头同 f 的切法，结尾不切，让词自然念完（w 反映 རྒྱལ་པོ 的 པོ 在整句里太短）。
- 挑选页去掉了「需要人工录音」选项（w 定的）。
- 短词补救（རིན་ཆེན、ས་གསུམ、ས་ཡི、སྙིང་པོ）：h/i/j=语速0.65 seed0/1/2，k/l=0.55 seed0/1，m=0.65 低噪声；n/o=སྙིང་པོ 前连 0.65/0.55；p/q=前面垫「ཨ་」再切（0.65/0.55）；t/u=垫「ཐབ་」；v/w=垫「དག་」，在 ས 起点切。
- 查明：词首 ས 发不出声是模型本身的问题（只给一帧，几乎没有 s 的气声），不是切静音切掉的；放慢反而更弱。垫一个音一起念能让 s 出来（ས་གསུམ 用 ཨ་，ས་ཡི 用 དག་）。
- 2026-10-25 w 挑完 149 个词：79 个连读(f)、51 个前连(g)、其余单独念/放慢/垫音。用 `python3 tools/lexicon.py picks <候选目录> <picks目录>` 换进词库（picks 从挑选页数据库导出）。换之前的词库备份在 lexicon/candidates/bo_before_picks/。以后新仪轨的词也走同样流程：生成候选 → 挑选页 → picks 导入。
- 交付给别人的单文件版：`python3 tools/build_offline.py deliver/仪轨念诵.html`（先跑 build_app.py）。去掉 Google 字体外链，藏文字体打包进去，断网用 file:// 打开也能用（已测试手机和电脑尺寸）。

- 离线版（deliver/仪轨念诵.html）只在 w 说需要时才重新生成，平时只更新阅读页。（w 2026-10-25）
- 功德颂这类偈颂体的说明段落（@outro.bo / @outro.zh）：藏文连成一段，汉文按句排整齐（两句一行）。（w 2026-10-25）
- 种子字（ཨོཾ ཨཱཿ ཧཱུྃ ཧྲཱིཿ 等）先不放发音、不用 AI 生成，以后统一用真人录音处理；名单在 tools/lexicon.py 的 SEED。（w 2026-10-26）
- 科判：原文有科判的仪轨，按科判分 == section（每段写 title.zh），并在头部加 @kepan: yes，阅读页顶栏会显示当前科判标题。没有科判的不加。（2026-10-26）
- 段落 id（== 后面的名字）定下来后尽量不要改：组合里的“安住”是按段落 id 记的（rests[].after = section.id），改 id 会让已设的安住失效。重新分段时保留原 id。（2026-10-26）
- 常用念诵：短小的常用念诵（供养偈、布施咒、回向偈、吉祥偈、加倍咒等）在头部加 @common: true，可选 @common.group（供养/回向/咒语…）分组，会出现在“常用念诵”页。（2026-10-26）
