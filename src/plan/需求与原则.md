# 互动式仪轨课诵修法：需求与原则

发心：为利益一切众生发菩提心而制作，帮助初学者学习仪轨/修法的藏文发音与含义。

## 传承限制（严格遵守）
- 只收录公开的、不需要灌顶的法本。
- 需要灌顶的内容不得公开显示或分发。数据格式里为每部仪轨保留“限制”标记，默认不公开。
- 用户自行添加的仪轨只保存在其本人设备上，不自动共享。

## 功能需求
1. UI 简洁，像阅读器。
2. 显示层自由组合：藏文、汉文、汉文音译、英文、英文音译（拉丁字母注音）、藏汉/藏英逐词对应，可单独或任意组合；可用颜色/下划线对照藏文与译文的意思。
3. 语音：点击偈颂发音；播放整部仪轨时逐字高亮，对应藏文与汉文。
4. 模块化：仪轨及其中各段可自由调整顺序与重复次数。
5. 播放速度两种调法：设定总时长自动调速，或用户手动调节速度。
6. 播放音轨可选：藏文 / 中文 / 只有调子。
7. 可自行添加未收录的仪轨。

## 优先级
- 文字一律以中文版（喇荣课诵）为准。
- 第一版重点做藏汉；英文、英文音译数据已保留，界面以后再开放。

## 已定的决定（2026-10-24）
- 按念诵的节拍拆分，不提供“按词”选项；逐词释义只在点开某一节时作补充。节拍不固定：七言偈常见 2-2-2-3，也有 2-2-3、九言、长行文等，每个仪轨、甚至每一句都可以单独定（数据里每句的 beats 自己写分组）。拿不准的节拍由 w 定。
- 显示面板只保留：常用组合、显示内容（藏文/汉文音译/汉文/意译 + 颜色对照）、汉文版本、字号。
- 汉文多版本：汉文1（新版）、汉文2（旧版），记住每部仪轨上次选的版本。
- 文本授权：已确认没有问题。

## 分发方式（w 2026-10-26 定）
- 不做服务器托管，以“下载后放在桌面”为主。
- 电脑（Windows/Mac）：单个离线 html 文件，下载后双击用浏览器打开。
- 安卓：同一个离线文件用 Chrome 打开；更稳可打包成 APK 直接安装（不上架）。
- iOS：单个文件在“文件”里只能预览、不运行程序，所以用“网页加到主屏幕”：放在免费静态空间给一个网址，第一次打开后可离线使用。用的人多了再考虑开发者账号 + TestFlight/App Store。
- 离线版只在 w 说需要时才重新生成。
- iOS 网页版放在 w 的 GitHub 公开仓库 jangchubgyaltsen/daily_recitation_reader（GitHub Pages，网址 https://jangchubgyaltsen.github.io/daily_recitation_reader/）。生成：python3 tools/build_pages.py <仓库目录>（直接从模板生成，不经过离线版），再提交推送。音频是单独文件 a/<内容哈希>.mp3，不打包进网页，所以没有 16 MB 限制；网页约 0.7 MB，音频打开后在后台存到手机上，离线可用（w 2026-10-26 同意）。离线版不再更新（w 2026-10-26）。网页版是主版本，首页要有「下载音频包」按钮，原音质不压缩；claude.ai 上的阅读器只作预览，词库发音继续压缩放进 16 MB（w 2026-10-27 选定）。

## 形式
- 先做 PWA（可离线、可装到手机主屏）。
- 若 PWA 不够用（主要风险：iOS 锁屏后台播放不稳定），再用 Capacitor 包成 App，代码可沿用。
- 组合念完后的结束页（w 2026-10-26）：满屏只写“随喜赞叹 / 愿一切众生早日成佛”，左上角返回箭头回仪轨库。常用页单独播一遍不算组合，不显示这页。
- 总时长的两种填法（w 2026-10-26 补）：设定总时长时选“念诵变速”（安住不变，念诵加快或放慢）或“安住拉长”（念诵原速，所有安住按比例拉长或缩短填满）。存在组合的 fill 字段里（speed / rest）。
- 没有录音的仪轨（w 2026-10-26）：照样能播，不发声、不用词库发音，按每个音节 0.45 秒、句间 0.6 秒估出节拍，高亮一节一节走；时长和组合总时长也按这个估。实现上是一段同样长的静音音频 + 推出来的节拍时间。
- 常用页（和藏历推荐）点播放不进阅读页，留在原页，只出迷你播放条（w 2026-10-26）。
- 设置整理（w 2026-10-26 定）：阅读页齿轮只管显示，半屏，去掉六个显示组合，只留藏文/音译/汉文/意译四个开关和颜色对照开关；字号一个滑条，各行分别调收进“分别调整”；行距紧凑/适中/宽松三档。首页齿轮进“设置”页：默认速度、新加安住的声音、殊胜日设置、备份导出导入、数据来源与致谢、版本。制作工具暂不隐藏（w 还在加仪轨），放在阅读设置最下面。
- 阅读设置再简化（w 2026-10-26，参考图是胶囊滑条）：不要小标题，一行单字圆钮：藏 音 汉 意 | 色 | 新 旧；字号一根胶囊滑条（圆钮上显示藏文字号，如 24）；边距、行距两根胶囊滑条并排（小/大、紧/松）；底部一行小字：分行字号、制作工具、恢复默认、完成。面板不超过半屏，不滚动。新增边距设置（S.mpad，0–64px）。
- 字鱼相随（w 2026-10-26，取代“只有调子”和“无录音”）：每部仪轨默认用这个模式。木鱼一拍一个词（beat_group），间隔绝对固定，不跟录音；间隔取这部仪轨录音节拍间隔的中位数（夹在 0.4–1 秒），没有录音就 0.6 秒，调速按比例。每拍同样轻重，句尾一拍稍重稍低。句与句之间不加空拍。时长和组合总时长都按这个算。没有录音的仪轨只有这一个选项。
- 打包体积：词库发音构建时压成 32 kbps（lexicon/bo-32k/ 缓存），整页才在 16 MB 以内。
- 打开 app 时的法相（w 2026-10-26）：网页版每次打开随机显示一张上师法相（pages/splash/ 里的图，不连续重复），加载完至少停留约 1.2 秒后淡出，点一下可跳过。图片已裁掉截图的状态栏、水印和音符图标，压缩到每张一百 KB 左右，和音频一样缓存在手机上。预览版（artifact）因为大小限制不显示。以后加图就放进 pages/splash/ 重新生成网页版。
